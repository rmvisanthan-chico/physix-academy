HTML5 Simulation Set

Standalone rebuilds using plain HTML5 Canvas and WebGL. No build step, no framework, and nothing fetched from the network — the 3D set loads Three.js from your own js/vendor/ folder plus one shared helper, lib/physix3d.js, both committed alongside. Open any one directly with file:// and it works.
