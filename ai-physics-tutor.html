The Offline AI Physics Tutor

Ask a numerical physics question and get the steps, not just the answer — computed in your own browser, with no account and no external AI service.

Most "AI tutor" tools send your question to a server. This one does not. The tutor is a deterministic solver that runs entirely in the browser: it reads the quantities in your question, picks the right relationship, and shows the substitution and the result. That means it works offline, costs nothing to run, and never stores your homework.

What it solves

Electricity

Ohm's law — given any two of voltage, current and resistance, find the third; series and parallel combinations.

Optics

Mirror and thin-lens problems: object distance, image distance, focal length and magnification, with the sign convention written out.

Kinematics

Uniform acceleration problems — initial velocity, final velocity, acceleration, distance and time.

Energy

Kinetic energy and its relation to mass and speed, including the squared dependence students most often miss.

Waves

Echo and sound problems: distance from time delay, using the speed of sound.

Read aloud

Any lesson can be read aloud with the browser's speech engine, at your own pace.

What it does not do

It is not a general chatbot. It is a solver for a defined set of numerical relationships, built so that every step it prints is checkable. If a question falls outside that set, it says so instead of inventing an answer. That constraint is deliberate: a wrong number explained confidently is worse than no answer.

How it is built

The tutor is a set of pure functions over parsed inputs, shipped as static JavaScript with the rest of the site. There is no model download, no API key and no usage limit. The same library of relationships drives the practice questions, so the tutor and the quiz cannot disagree about a formula.

Common questions

Is it really free?

Yes — no account, no credits, no ads. See free learning.

Does it need internet?

Only to load the page the first time. Once loaded, the solver runs locally and the site keeps working offline.

Is my question stored?

No. The solver runs in the page and nothing is sent to a server.
